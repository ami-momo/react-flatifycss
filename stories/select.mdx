# Select

<p className="component-doc-intro">A styled native select, so it stays accessible and works well on phones, with grouped options and multiple choices.</p>
<div className="funky-spacer" />

## Default

Pass an array of options with `options` prop, use `value` with `onChange` to update data.  
If you do not set the value, it will be set internally as an uncontrolled component by default, you can use `onChange` event to get the updated value, it returns selected options and event.

<Canvas of={SelectStories.Default} />

## Grouped

It is possible to organize options with groups, just add the group items with `options` inside your first level items.

<Canvas of={SelectStories.Grouped} />

## Controlled

To have a controlled select component just set the value yourself.

<Canvas of={SelectStories.Controlled} />

## Multiple

Selecting multiple options is interesting, add the `multiple={true}` to have one. In this case `value` is an array.

<Canvas of={SelectStories.Multiple} />

## Inline label

The label is above the select by default, add `inlineLabel` to put it on the same line.

```jsx
<Select label="Choose your car" inlineLabel options={options} />
```
