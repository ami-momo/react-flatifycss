## Show / hide

To toggle the alert visibility state, set the `show` to `true` or `false`. Note that `show={false}` will unmount the alert component. The default example above works this way: the close button sets `show` to `false`, and the "Show Again!" button sets it back to `true`.

```jsx
const [show, setShow] = useState(true);

<Alert show={show}>
  <AlertCloseButton label="Close the alert" onClick={() => setShow(false)} />
  Your message
</Alert>
```

## Icon

## Floating close button

Alert comes with an `<AlertCloseButton />` component which reserves its parent space, another way is to make it come over the content and be displayed while focused or the parent is hovered, to do so add the `floating` prop to the `<AlertCloseButton />` component.

## Animation

To change the default dismiss animation use the `animation` prop and set your custom animation like `my-custom-animation 0.4s ease`.
