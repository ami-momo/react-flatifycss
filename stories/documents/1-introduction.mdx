# Welcome!

<p className="component-doc-intro"><a href="https://flatifycss.amimomo.me" target="_blank">FlatifyCSS</a> is an open-source, minimalist flat design web framework inspired by the Duolingo design system, it is written in pure web technologies.</p>
<p className="component-doc-intro">On the other hand <mark className="inline style-blue">React FlatifyCSS</mark> actually is an implementation of FlatifyCSS available components and styles based on React.</p>
<div className="funky-spacer" />

FlatifyCSS has a playful design and gives you features to help you develop your project quickly and easily:

- <mark className="inline style-blue-light">Customizability</mark>

  With the power of CSS custom properties, it is possible to customize colors, typography, animations, etc. You can do the customization for each component or generally from the config file.

  <div className="funky-spacer-sm" />

- <mark className="inline style-green-light">Accessibility</mark>

  It is keyboard-friendly, the friend of assistive technologies, and supports the reduced motion for animation and transitions when the user prefers.

  <div className="funky-spacer-sm" />

- <mark className="inline style-orange-light">Support for right to left layouts</mark>

  FlatifyCSS uses CSS logical properties, so the same stylesheet works for right to left languages like Arabic, Persian, Hebrew, etc. Just set `dir="rtl"` on your page.

  <div className="funky-spacer-sm" />

- <mark className="inline style-purple-light">Practical set of components</mark>

  There are more than twenty components that can be mixed and make more complex user interfaces, each component has its unique CSS variables and can be customized based on the usage.

  <div className="funky-spacer-sm" />

- <mark className="inline style-pink-light">Based on Styled Components</mark>

  The components are created based on styled-components, so you can add your styles and get benefits of using styled components with joy.
