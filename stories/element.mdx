## Common example

Let's create a card with the `<Element />` component, using `sx` prop to apply styles with styled-components library and `as` prop to define the semantic for HTML tag.

## Props

`<Element />` takes any prop and passes it to the HTML element, plus the [common props](?path=/docs/documents-common-props--docs). It renders a `<div>` unless you change it with `as`.
