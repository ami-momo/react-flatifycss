## Loading

## States

The `state` prop keeps the button in one look: `active` looks pressed, `static` does not react to hover and clicks, and `disabled` disables it, same as the `disabled` prop.

```jsx
<Button state="active">Active</Button>
<Button state="static">Static</Button>
<Button state="disabled">Disabled</Button>
```
