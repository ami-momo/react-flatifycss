# Radio

## Default

To have a **controlled** radio (that you control the checked state yourself), add the `checked` prop.  
To toggle, you can use the second argument of `onChange` event like so, `onChange={(e, checked) => setChecked(checked)}`

<Canvas of={RadioStories.Default} />

## Uncontrolled

You can specify the radio default value with `defaultChecked` prop, then toggle by using the `onChange` second argument.

<Canvas of={RadioStories.Uncontrolled} />

## Multiple

When you want to choose one option from available options, give all the radios the same `name` and each one its own `value`.  
Keep the selected value in your state, a radio is `checked` when its value matches it, and the third argument of `onChange` is the value of the radio that was just selected:
`onChange={(e, checked, value) => setSelected(value)}`
