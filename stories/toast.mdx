# Toast

<p className="component-doc-intro">To notify users and communicate, you need something like toasts that come on top of each other and will get hidden after an amount of time.</p>
<div className="funky-spacer" />

## Default

To show/hide the toast, change the `show` prop value for `<Toast />` component.

### Toast wrapper

Toasts need wrapper to be appended to, so before using them add the **`<ToastsWrapper />`** somewhere in your app, **it should be added once**. The examples on this page each include their own wrapper so they also work alone in the canvas, do not copy that part.

<Canvas of={ToastStories.Default} />

## Icon

Use the `<ToastIcon />` component inside `<Toast />`, its content would be a svg.

<Canvas of={ToastStories.Icon} />

## Close button

To enable the close button for a toast, add the `closeButton` to `<Toast />` component.  
The close button does not close the toast by itself, it emits the `onClose` event and you set `show` to `false`.  
Note that close button does not have any text inside, so you should set a label with `closeButtonLabel` prop, that will be used by screen readers.

<Canvas of={ToastStories.CloseButton} />

## Auto close

By default the toast will not get hidden but if you add the `autoClose={true}` to `<Toast />`, it will emit the `onClose` event after given duration that is default to `3000ms`.

## Position

By mixing the `y` and `x` props, it is possible to change the toast position.

### X-axis position

Possible values are: `right`, `left` and `center` (default).

<Canvas of={ToastStories.XPosition} />

### Y-axis position

Possible values are: `top` and `bottom` (default).

<Canvas of={ToastStories.YPosition} />

## Custom animation

It is possible to use your custom animation to show and hide toasts, set the `showAnimation` and `hideAnimation` to `<Toast />`, the expected value is a CSS animation like this: `toast-custom-show-anim ease 0.3s`.

<Canvas of={ToastStories.CustomAnimation} />

## Screen readers

Toasts are announced politely by default (`role="status"`). For urgent messages like errors, set `type="alert"`, then screen readers interrupt the user to read it.

```jsx
<Toast show={hasError} type="alert">Payment failed, please try again.</Toast>
```
