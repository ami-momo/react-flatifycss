# Modal

<p className="component-doc-intro">Modal, pop-up box, bottom sheet, off-canvas, anything can be related to this component, we generally call it modal. There are different types of modals with different sizes and styles that come with FlatifyCSS, which we will cover with practical examples on this page.</p>
<div className="funky-spacer" />

## Default

To hide and display the modal use `isOpen` prop for the `<Modal />` component, also you can listen to change this prop to hide the modal with `onDismiss` prop, like this `onDismiss={() => setIsOpen(false)}`.

<Canvas of={ModalStories.Default} />

### Modal parts

Each modal can have `<ModalHeader />`, `<ModalBody />` and `<ModalFooter />` components inside as children.

```jsx
const [isOpen, setIsOpen] = useState(false);

<Button onClick={() => setIsOpen(true)}>Open</Button>
<Modal isOpen={isOpen} onDismiss={() => setIsOpen(false)} aria-labelledby="modal-title">
  <ModalHeader>
    <h5 id="modal-title">Hello!</h5>
  </ModalHeader>
  <ModalBody>Some content</ModalBody>
  <ModalFooter>
    <Button onClick={() => setIsOpen(false)}>Close</Button>
  </ModalFooter>
</Modal>
```

## Disable overlay click

By default, if the user clicks on the modal overlay, the modal will be dismissed.  
However, sometimes the action is required, and it should be dismissed only after an action, to do so you can set the `disableOverlayClick={true}` for `<Modal />` component.

## Bordered

In this case, the header and footer will have borders to get separated visually from the body.

## Positioned

Modals can be opened from top, bottom, right and left sides, just set the `position` for `<Modal />` component. Possible values are `center`, `top`, `bottom`, `left` and `right`. Each side will have its special animation.

<Canvas of={ModalStories.Positioned} />

## Custom overlay

With `overlayClassName` prop, it is possible to pass a custom class to modal overlay, so to style it.  
Note that **passed class styles should be global**. For example, styles with `sx` prop will not work, because the overlay itself is appended to the body, not inside the modal.
